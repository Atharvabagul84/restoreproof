- On 2026-10-25 the owner approved publishing this repository as an MIT-licensed portfolio project (the bundled Chisel snapshot is also MIT). Change visibility only with the owner's explicit go-ahead; keep any new project repositories private unless the owner decides otherwise. Never commit real account IDs, bucket suffixes, local paths or credentials (see CONTRIBUTING.md).
- Use free tools and services only. The user has not authorized service charges, paid plans, paid API calls, or upgrades when a free allowance expires.

- Hosted validation is disabled unless the repository variable `RESTOREPROOF_FREE_CI_VERIFIED` is exactly `true`. Do not enable it without satisfying the cost policy. A skipped job is not test evidence.
- Follow [the cost policy](docs/reference/cost-policy.md) and the revision-specific validation records. Do not claim local emulator results validate real AWS IAM, OIDC, or hosted recovery. The owner authorized the offline report and the weekly synthetic GitHub lab on 2026-10-07. The synthetic lab has an independent opt-in gate and creates fresh fixtures without AWS credentials. Enable its timer only after hosted reproduction passes and free-use controls are verified. AWS scheduling remains blocked until its own authentication and fresh-backup prerequisites pass. Preserve AWS-managed account policies.
